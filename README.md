# Grand Theft Auto VII — Fan Concept Website

A fan-made concept website for **Grand Theft Auto VII (GTA 7)**, inspired by the cinematic design and presentation of Rockstar Games' official Grand Theft Auto VI website.

This project explores what a future Grand Theft Auto game website could look like, featuring a modern interface, cinematic visuals, smooth animations, and responsive layouts.

## Features

- GTA VII-inspired landing page
- Cinematic, full-screen design
- Responsive layout for desktop and mobile
- Smooth scrolling and animations
- Fictional game setting and characters
- Trailer and media showcase sections
- HTML, CSS, and JavaScript
- Compatible with GitHub Pages

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Installation

1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Explore the website.

No additional software or dependencies are required.

## Deploying to GitHub Pages

1. Open the repository's **Settings**.
2. Navigate to **Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose the `main` branch and `/(root)` folder.
5. Click **Save**.

Your website should become available at:

`https://YOUR-USERNAME.github.io/GTA7/`
